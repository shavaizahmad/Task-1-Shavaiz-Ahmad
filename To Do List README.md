# 📝 Python To-Do List Application

A simple and beginner-friendly **To-Do List Application built with Python** that allows users to add tasks, view their tasks, and store task data permanently using JSON file handling.

This project was developed as part of my Python learning journey at **DecodeLabs**.

## 🚀 Features

- **Add Tasks:** Add new tasks to your to-do list.
- **View Tasks:** Display all previously added tasks with their IDs.
- **Data Persistence:** Save tasks in a JSON file so they remain available after restarting the program.
- **Automatic Task Loading:** Load previously saved tasks when the application starts.
- **Input Validation:** Check user input for valid menu options and Y/N responses.
- **Menu-Driven Interface:** Simple and easy-to-use command-line interface.

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Loops and Conditional Statements
- Functions
- Lists and Dictionaries
- Exception Handling

```text
To-Do-List/

```

- `Project.py` — Contains the main Python application.
- `tasks.json` — Stores tasks in JSON format.
- `README.md` — Provides project information and instructions.

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python Project.py
```

## 📋 How to Use

When you run the application, you will see these options:

1. **Add Task** — Enter a new task.
2. **View Task** — Display all saved tasks.
3. **Exit** — Close the application.

Your tasks are stored in `tasks.json` and loaded when you run the application again.
