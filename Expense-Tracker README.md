# 💰 Python Expense Tracker

A beginner-friendly **Expense Tracker application built using Python** to manage money, record daily expenses, track total spending, and calculate the remaining balance.

This project was developed as part of my Python learning journey at **DecodeLabs**.

## 🚀 Features

- **Add Money:** Add money to your total available balance.
- **Add Expenses:** Record expenses and keep track of money spent.
- **View Expenses:** Display recorded expenses for easy tracking.
- **Total Spending:** Calculate the total amount spent on expenses.
- **Remaining Balance:** Check how much money remains after expenses.
- **Input Handling:** Accept user input to interact with the application.
- **Menu-Driven Interface:** Navigate through different options using a simple menu.
- **Continuous Interaction:** Use a loop to perform multiple operations until choosing to exit.

## 📋 Application Menu

The application provides options to manage your money:

| Option | Description |
|---|---|
| Add Money | Enter money to increase your available balance. |
| Add Expenses | Record an expense and update your spending total. |
| View Expenses | View the expenses recorded in the application. |
| View Total Spending | Check the total amount spent. |
| View Remaining Balance | Calculate the balance left after spending. |
| Exit | Close the application. |

*Note: The exact menu options depend on the implementation in your Python code.*

## 🛠️ Technologies Used

- **Python 3** — Core programming language.
- **Variables** — Store balances, expenses, and totals.
- **User Input** — Collect choices and amounts from the user.
- **Loops** — Keep the application running until the user exits.
- **Conditional Statements** — Execute different operations based on menu choices.
- **Functions** — Organize and reuse code where implemented.
- **Basic Arithmetic** — Calculate total spending and remaining balance.

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python expense_tracker.py
```

5. Follow the menu instructions to add money, record expenses, view totals, and check your remaining balance.
